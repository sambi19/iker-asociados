Publicar una novedad

Llene el formulario y copie el texto que aparece abajo dentro del archivo data/jurisprudencia.json del repositorio. No hace falta escribir código.

Cómo se publica

  1. Complete los campos y pulse Generar.
  2. Pulse Copiar.
  3. Abra el archivo public/data/jurisprudencia.json en GitHub y pulse el lápiz para editarlo.
  4. Pegue el bloque copiado justo después del primer corchete [, seguido de una coma si ya hay otras entradas.
  5. Pulse Commit changes. Cloudflare publica el cambio en menos de un minuto.

Esta página es solo una ayuda para redactar. No guarda nada por sí sola: el cambio se publica cuando usted lo confirma en GitHub.
